Set up two-factor login

For the safety of student records and school money, every administrator must sign in with a second step: a 6-digit code from an authenticator app on their phone.

  1. Install Google Authenticator, Microsoft Authenticator or Authy on your phone.
  2. Scan the QR code we show you.
  3. Type the 6-digit code to finish.

Scan, then confirm
